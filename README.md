# 🏓 Pong (TP1 - Desarrollo de Videojuegos)

Este proyecto es un **juego estilo Pong** desarrollado en **Godot** como
parte del **Trabajo Práctico 1 (TP1)** de la materia **Desarrollo de
Videojuegos**, dictada por el profesor **Santiago Beitia**.

El juego permite seleccionar mapa y cantidad de jugadores antes de
iniciar la partida.

------------------------------------------------------------------------

# 🎮 Características

-   Selección de mapa
-   Modo **1 jugador (contra bot)**
-   Modo **2 jugadores**
-   Rebotes con ángulo dependiendo del punto de impacto
-   Aumento progresivo de velocidad de la pelota
-   Sistema de goles y reinicio desde el centro

------------------------------------------------------------------------

# ⚙️ Instalación

## Opción 1 --- Descargar desde Releases (Recomendado)

1.  Ir a la sección **Releases** del repositorio.
2.  Descargar el archivo `.zip` de la última versión.
3.  Extraer el contenido.
4.  Ejecutar:

```{=html}
<!-- -->
```
    pong.exe

No es necesario instalar nada más.

------------------------------------------------------------------------

## Opción 2 --- Ejecutar desde el proyecto (Godot)

1.  Descargar o clonar el repositorio:

```{=html}
<!-- -->
```
    git clone https://github.com/USUARIO/REPOSITORIO.git

2.  Abrir **Godot Engine**.
3.  Seleccionar **Import**.
4.  Abrir el archivo:

```{=html}
<!-- -->
```
    project.godot

5.  Ejecutar el proyecto.
